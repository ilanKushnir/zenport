# Code of Conduct

ZenPort follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, assume good faith, and keep discussions about the work. Harassment, discrimination, and personal attacks are not tolerated anywhere in the project's spaces.

Violations can be reported privately to the maintainer via the contact listed on the GitHub profile. Reports are handled confidentially.
